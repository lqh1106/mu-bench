The challenge

More than taking turns.

A coherent reply is only the beginning. The agent must keep requests attached to their owners and bring interdependent tasks to a jointly valid result.

Tool-Free

Coordinate through conversation.

Answer, clarify, refuse, and resume requests using spoken interaction.

49 scenarios · 392 cases

Tool-Augmented

Follow through in the environment.

Connect what was said to actual tool execution and the final business state.

51 scenarios · 408 cases

Every scenario has eight controlled variants: group size × acoustics × follow-up demands.

The framework

Live interaction. Verified outcomes.

Reactive user simulation shapes the conversation. Independent semantic reviews and programmatic checks establish what actually happened.

Primary outcome

Joint Task Success

Applicable goals, tool effects, final state, and privacy must hold together in one trajectory.

Reproduce & build

Bring your voice agent.

Clone the benchmark, validate the included cases and voice assets, then configure your ASR, TTS, and model endpoints.

Installation guideModel adaptersSetup guide for agents
Quick start · Linux · Python 3.10–3.12
export MUBENCH_REPO="$HOME/mu-bench"
git clone https://github.com/lqh1106/mu-bench.git "$MUBENCH_REPO"
cd "$MUBENCH_REPO"
bash scripts/bootstrap.sh
.venv/bin/python -m mubench validate --assets
